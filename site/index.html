Archives Mattermost

Conservez l'historique de vos salons Mattermost sous forme de pages web lisibles hors ligne, et retrouvez n'importe quel message à partir de son lien.

Comment ça marche

1Exporter

Un administrateur exporte les salons via l'API Mattermost : messages, threads, réactions, liens et images.

2Mettre en page

Chaque salon devient un dossier avec une page index.html autonome, consultable sans connexion.

3Parcourir

La page sommaire.html réunit tous vos salons, et retrouve un message à partir de son lien Mattermost.

Télécharger

Vous avez reçu des salons exportés

  1. Décompressez les zips de vos salons dans un même dossier.
  2. Enregistrez sommaire.html dans ce dossier.
  3. Ouvrez-le d'un double-clic, puis choisissez ce dossier.
mes-archives/
├── sommaire.html
├── general/
└── cantine/
⬇ Télécharger sommaire.html

Vous voulez essayer

Un zip d'exemple avec sommaire.html et trois salons fictifs déjà exportés : Général, Cantine et Veille technique.

  1. Décompressez le zip.
  2. Ouvrez sommaire.html dans le dossier obtenu.
  3. Choisissez ce même dossier.

Vos données restent chez vous

Les archives s'ouvrent directement depuis votre ordinateur, sans serveur ni compte, dans n'importe quel navigateur récent. Votre navigateur peut parler d'« importer » les fichiers au moment de choisir le dossier : rien n'est envoyé, la page ne fait que les lire.

Pour exporter des salons

L'export se fait avec des scripts Python et un jeton d'accès Mattermost. Toutes les instructions sont dans le dépôt GitHub du projet.
